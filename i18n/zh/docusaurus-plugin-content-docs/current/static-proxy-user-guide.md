# 006ip 静态代理使用指南

## 一、如何购买静态住宅代理？

登录 006ip 的用户后台，左侧导航栏点击「静态代理」，选择「套餐购买」，在这个页面，就可以生成完整的静态代理信息，具体操作步骤如下：

### 1. 代理基础属性

![静态代理购买 — 基础属性配置](/img/static-proxy/purchase-basic-attributes.png)

在购买静态代理时，您需要首先完成基础属性的筛选与配置。系统将根据您的选择，实时生成对应的价格与库存状态：

- **独享级别：** 平台提供「共享」与「独享」两种资源分配模式。**共享 IP** 适合对成本控制要求较高的常规网络访问场景；**独享 IP**（仅限 1–2 人使用）则提供更高的环境纯净度与网络稳定性，适用于对 IP 关联度有严格要求的进阶业务场景。

- **IP 质量：** 划分为「基础」、「标准」与「高端」三个梯度。您可以根据目标平台的访问标准及自身业务的网络质量要求，匹配最合适的底层代理资源。

- **业务用途：** 为保障最优的连通率，平台针对主流场景进行了网络路由适配。您可以直接勾选热门选项（如 TK、Google、亚马逊、eBay 等），或点击「更多业务用途」展开完整类目，确保分配到的 IP 池能精准适配您的实际业务环境。

### 2. IP 配置（支持 3 种购买方式）

支持按城市采购、按 IP 段采购、指定 IP 采购三种方式。

#### 按城市采购

![静态代理购买 — 按城市采购](/img/static-proxy/purchase-by-city.png)

- **跨区资源组合：** 在地区配置模块，支持同时添加多个目标国家/地区，实现跨地域代理资源的统一采购。

- **精准区域定位：** 在已选国家列表下，您可以根据业务的地理位置要求，指定「固定城市」进行精准覆盖，或选择「随机范围」进行国家级的泛节点分布。

- **按需分配配额：** 在对应的城市或随机区域卡片中，直接输入所需提取的具体 IP 数量，系统将自动核算并锁定当前可用库存。

#### 按 IP 段采购

![静态代理购买 — 按 IP 段采购](/img/static-proxy/purchase-by-ip-segment.png)

- **锁定目标国家：** 根据实际业务的网络部署需求，在选框中添加单个或多个目标国家/地区。

- **网段细分筛选：** 选定国家后，系统默认加载并展示该区域下全量可用的 IP 子网网段。若需提高节点定位精度，可展开「细分筛选」下拉菜单，通过检索或点选具体城市，对底层 IP 段进行地理位置的精准过滤。

- **按段分配配额：** 在筛选出的城市 IP 段卡片中，核对对应的网段信息与可用库存，并直接输入所需的节点调配数量，即可完成该子网段的定向采购。

#### 指定 IP 采购

![静态代理购买 — 指定 IP 采购](/img/static-proxy/purchase-by-specific-ip.png)

- **锁定目标区域：** 首先在选框中勾选您需要部署业务的目标国家。

- **切换目标网段：** 选定国家后，系统面板将默认加载并展示该区域首个可用网段下的具体 IP 列表。您可以通过网段下拉菜单，检索并切换至您所需的特定 IP 网段。

- **精准点选节点：** 在下方的节点资源池中，系统会以卡片形式平铺展示该网段内所有可用的独立 IP。直接点击您需要的具体 IP 卡片即可完成精准指定，实现节点级别的精细化采购。

### 3. 更多配置以及订单详情

更多配置中的选择会影响价格计算。

![静态代理购买 — 高级配置与订单详情](/img/static-proxy/purchase-advanced-config.png)

- **端口带宽（Bandwidth）：** 提供从 5M/s、10M/s 至「不限带宽」等多个峰值速率梯度，您可以依据实际业务的网络数据吞吐需求进行灵活选配。

- **并发连接数（QPS）：** 即每秒查询率。系统预设了 100、500、1000 等常规档位，并支持「自定义」输入，全面适配从基础访问到高并发请求的各类网络环境。

- **UDP 协议支持：** 默认为关闭状态。若您的应用场景需要处理实时数据流或依赖特定的通信架构，可手动勾选「开启」（注：开启 UDP 协议支持将产生一定的附加费用）。

- **授权订阅时长：** 支持 7 天至 365 天等多个维度的生命周期管理。选择中长期（如 90 天、365 天）订阅套餐，系统将自动匹配并叠加阶梯式折扣优惠。

界面右侧的**订单详情**面板为您的实时账单核算中心。该区域会动态汇总您勾选的所有基础属性与高级配置参数，并按国家/地区节点清晰拆解明细。在为您核减「时长优惠金额」后，系统将输出最终的「支付价格」，点击「立即支付」即可进入订单确认页面。

### 4. 订单确认

- 进入订单确认页面会自动锁定已选择的 IP 资源 15 分钟，如果一直未支付过期会释放 IP 资源。

- 支持账户余额支付、在线支付、组合支付。当存在账户余额时，支持使用余额支付，账户余额不足时支持与在线支付组合支付。

- 使用账户余额支付需要输入在本平台设置的支付密码。

![静态代理 — 订单确认与支付](/img/static-proxy/order-confirm.png)

**资源库存锁定：** 进入 Checkout（订单确认）页面后，系统将根据您的配置清单，自动在底层网络池中锁定对应的代理 IP 资源库存。锁定期为 15 分钟，若超时未完成结算，系统将自动释放该批次节点的配额。

**灵活组合支付：** 平台结算网关支持「账户余额」、「在线支付」以及「余额 + 在线」的组合支付模式。当账户可用余额不足以覆盖全额订单时，系统优先扣减全额余额，剩余差价可无缝衔接主流在线支付渠道（如 USDT、微信支付、支付宝等）进行补齐。为保障资金账户安全，动用余额抵扣时需校验您的专属支付密码。

**结算状态同步（以微信组合支付为例）：**

1. 在支付面板勾选「微信支付」，点击底部按钮支付差额后，系统将生成专属在线收款二维码。

2. 移动端扫码付款完成后，请务必在系统界面点击「已支付」按钮，主动触发网关状态更新。

3. 随后系统将弹出「支付状态查询」对话框并向服务端发起校验。待回传「支付成功」指令，即代表资源已正式授权下发。

4. 点击弹窗右下角的「查看我的 IP」按钮，即可跳转至控制面板提取代理节点进行业务部署。

![静态代理 — 微信支付流程](/img/static-proxy/payment-wechat.png)

![静态代理 — 支付成功](/img/static-proxy/payment-success.png)

## 二、查看已购买的静态 IP

进入「我的 IP」菜单，可以查看所有已购买 IP 的信息，支持续费、停用、启用、导出账密等操作。

![静态代理 — 我的 IP 列表](/img/static-proxy/my-ip-list.png)

**节点状态监控：** 列表直观呈现各项核心网络参数（带宽、QPS、UDP 协议状态等），并实时追踪资源的使用状态（可用、已停用、即将到期、已过期保留等）。

**生命周期调度：** 在操作列中，支持对单一代理节点执行**续费**（延长授权期限）、**停用 / 启用**（按需阻断或恢复网络连接）以及查看底层网络**详情**，保障业务的连续性与灵活性。

**鉴权凭证导出：** 针对大规模集成需求，支持点击右上角的「导出账号」按钮，一键批量生成并下载代理节点的连接鉴权信息（账号/密码），便于快速对接到您的自动化业务运行环境中。

### 自动续费

到期后自动扣取账户余额进行续费。

![静态代理 — 自动续费设置](/img/static-proxy/auto-renewal.png)

开启此策略并设定触发阈值（如「到期 3 天前续费」），系统将在设定的临期节点，自动从您的账户可用余额中划扣相应款项并完成授权延期。该策略可有效避免因遗忘操作导致节点被系统释放，确保底层网络环境的长效稳定。

### 手动续费

![静态代理 — 手动续费](/img/static-proxy/manual-renewal.png)

当您需要即时延长代理节点的授权期限时，可通过「手动续费」功能进行单次结算。在弹窗面板中，您可通过下拉菜单灵活指定所需的「续费周期」（如 30 天）。系统将根据您选定的底层节点数量与续费时长，实时自动计算并展示对应的「预计金额」。

### 导出静态 IP 账密数据

![静态代理 — 导出账号凭证](/img/static-proxy/export-credentials.png)

为满足大规模环境部署与自动化集成需求，系统支持一键导出所选代理节点的连接凭证。

- **触发凭证提取：** 在明细列表界面右侧，点击「导出账号」按钮，唤出配置面板。系统将默认基于您当前的列表筛选条件，精准圈定需要导出的目标 IP 范围。

- **配置数据交互格式：** 在弹窗面板中，您可通过「代理格式」下拉菜单，灵活选择匹配第三方软件或自研脚本的数据排列结构（如标准的 `IP:PORT:USERNAME:PASSWORD`），以实现底层业务系统的无缝对接。

- **安全核验与执行导出：** 由于导出的文件包含明文的 IP、端口及账号密码凭证，出于最高级别的网络资产安全管控要求，您必须在指定输入框内填写当前账户的「登录密码」进行身份核验（此操作将自动写入系统审计日志）。验证无误后，点击「确认导出」即可安全获取节点配置文件。

## 三、测试静态 IP 连通性

在获取节点鉴权凭证后，建议您通过本地终端命令行进行基础的网络连通性与出口 IP 验证。以下为基于 `curl` 工具的 IPv4 和 IPv6 节点测试命令规范：

### IPv4 测试命令

```bash
# http
curl -x http://username:password@IP:PORT https://ifconfig.co

# socks5
curl -x socks5h://username:password@IP:PORT https://ifconfig.co
```

![静态代理 — IPv4 连通性测试](/img/static-proxy/ipv4-connectivity-test.png)

在发起请求前，请将上述命令中的 `username:password@IP:PORT` 替换为您实际提取的节点鉴权信息。在终端执行该命令后，系统会通过代理节点向目标检测站点（如 ifconfig.co）发起访问；若网络连通与鉴权均正常，终端将直接返回该代理节点的真实出口 IP 地址。核对返回结果与所购节点 IP 一致，即代表该资源已准备就绪。

### IPv6 测试命令

```bash
# http
curl -x http://username:password@[IPv6]:PORT https://v6.ipinfo.io

# socks5
curl -x socks5h://username:password@[IPv6]:PORT https://v6.ipinfo.io
```

![静态代理 — IPv6 连通性测试](/img/static-proxy/ipv6-connectivity-test.png)

请将命令中的鉴权信息替换为您的真实节点凭证。执行请求后，代理节点将向支持纯 IPv6 访问的检测站点（如 `v6.ipinfo.io`）发起路由转发。若测试成功，终端将以 JSON 格式完整返回该节点的地理位置快照（包含真实的出口 IPv6 地址、城市、ASN 机构等网络环境信息），您可借此比对资源状态是否符合预期。
